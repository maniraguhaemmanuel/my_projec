# Emmanuel Maniraguha — ICT & NIT Portfolio

A personal portfolio website for **Emmanuel Maniraguha**, an ICT and Network Information Technology (NIT) professional and technology educator. The project presents my background, technical skills, practical projects, education and professional development, with a focus on computer networking, cybersecurity, IoT, Git/GitHub, quality assurance, fiber-optic networking, Windows Server, zero-client technology, and practical ICT training.

## Features

- **About Me Section:** Introduction, professional focus, and areas of interest.
- **Skills Section:** Networking, cybersecurity, IoT, Git/GitHub, HTML/CSS, fiber optics, servers, and technical training.
- **Projects Section:** Selected academic, practical, and technology projects.
- **Education & Professional Development:** Technical learning and continuous professional development.
- **Contact & Links:** GitHub profile and project repository links.
- **Responsive Design:** The website adapts to desktop, tablet, and mobile screens.

## How to Run This Project

### Option 1: Run Locally

You only need a modern web browser.

#### Prerequisites

- A computer
- Git
- A modern web browser such as Google Chrome, Microsoft Edge, Firefox, or Safari
- Optional: Visual Studio Code or another code editor

#### Installation

1. Clone the repository:

```bash
git clone https://github.com/maniraguhaemmanuel/my_projec.git
```

2. Enter the project directory:

```bash
cd my_projec
```

3. Open `index.html` in a web browser.

4. Alternatively, open the project folder in Visual Studio Code and use a local development server.

## How to Access the Online Portfolio

The project can be hosted using **GitHub Pages**.

1. Push the project files to your GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select the `main` branch as the source.
5. Save the settings.
6. GitHub Pages will publish the website.

The published address will normally follow this format:

```text
https://maniraguhaemmanuel.github.io/my_projec/
```

If a custom GitHub Pages URL is configured, use that URL instead.
